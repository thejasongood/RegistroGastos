# Registro de Gastos

Programa desarrollado en C# que utiliza ADO.NET para conectarse a SQL Server, consultar los gastos registrados y calcular el total gastado.

## Funciones principales

- Conectar con la base de datos SQL Server.
- Consultar y mostrar los gastos registrados.
- Calcular el total de los gastos.
- Mostrar un mensaje cuando no hay registros.

## SqlException.

Se produjo una `SqlException` porque se cambió temporalmente el nombre de la base de datos a `GastosProbar`, que no existía o no estaba disponible. SQL Server generó el error 4060 al no poder abrir la base de datos solicitada.
